API Ventas Tech

Servicios REST para gestionar ventas, consolidación de métricas y operación del catálogo de productos. Diseñada para integraciones rápidas, respuesta JSON estructurada y fácil consumo desde aplicaciones web, móviles o sistemas internos.

4Endpoints clave
JSONRespuestas estándar
RESTArquitectura base
MySQLPersistencia

Endpoints principales

Base URL: /api/v1
GET /api/v1/ventas/consolidado

Obtiene el consolidado de ventas con información resumida del total registrado por operación.

Parámetros

NombreTipoDescripción
--No requiere parámetros.

Códigos HTTP

200 OK 500 Error
Ejemplo de respuesta
{
  "status": "success",
  "total_registros": 4,
  "data": [
    { "id_venta": 1, "total_venta": 145000, "fecha_venta": "2026-10-28" },
    { "id_venta": 2, "total_venta": 89000, "fecha_venta": "2026-10-27" }
  ]
}
POST /api/v1/ventas

Crea una venta con productos y datos relevantes de la transacción.

Body

CampoTipoRequerido
id_clientenumberSi
fecha_ventastringSi
total_ventanumberSi

Códigos HTTP

201 Created 400 Bad Request
Solicitud
{

  "fecha_venta": "2026-10-28",
  "total_venta": 145000,

    { "id_producto": 1, "cantidad": 2 }
  ]
}
PUT /api/v1/ventas/:id

Actualiza una venta existente según su identificador. Permite modificar total, cliente o información relacionada.

Parámetros

CampoTipoDescripción
idnumberIdentificador de la venta en la URL.
total_ventanumberNuevo monto total.

Respuesta

200 OK 404 Not Found
Ejemplo de actualización
{
  "id_cliente": 12,
  "total_venta": 163500,
  "estado": "actualizada"
}

Catálogo de productos

Operación de mantenimiento
DELETE /api/v1/productos/:id

Elimina un producto del catálogo usando su identificador único.

Parámetros

NombreTipoDescripción
idnumberIdentificador del producto a eliminar.

Códigos HTTP

200 OK 404 Not Found
Respuesta esperada
{
  "status": "success",
  "message": "Producto eliminado correctamente",
  "id_producto": 8
}

Formato de respuesta

Todas las respuestas de la API siguen una estructura uniforme para facilitar la integración y depuración.

Respuesta exitosa

JSON
{
  "status": "success",
  "timestamp": "2026-10-28T12:00:00.000Z",
  "data": [
    { "id_producto": 1 }
  ]
}

Error

JSON
{
  "status": "error",
  "timestamp": "2026-10-28T12:00:00.000Z",
  "message": "Parámetros inválidos"
}
200 OK 201 Created 400 Bad Request 404 Not Found 500 Internal Server Error

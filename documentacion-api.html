API Ventas

Documentación del servicio

API para consultar ventas consolidadas y registrar nuevas transacciones de venta en la base de datos.

URL Base
http://localhost:3000/api/v1/ventas
Archivo base analizado
server.js

Endpoints principales

GET /api/v1/ventas/consolidado

Parámetros query

  • sucursal: requerido. Tipo: string o number.
  • anio: requerido. Tipo: number o string.
Ejemplo: GET /api/v1/ventas/consolidado?sucursal=1&anio=2024

Códigos de respuesta

200 OK 400 Bad Request 500 Internal Server Error

Respuesta exitosa (200)

{
  "status": "success",
  "total_registros": 2,
  "data": [
    {
      "id_venta": 1,
      "sucursal": "Sucursal Centro",
      "anio": 2024,
      "mes": "Enero",
      "total_ventas": 1200.5
    },
    {
      "id_venta": 2,
      "sucursal": "Sucursal Centro",
      "anio": 2024,
      "mes": "Febrero",
      "total_ventas": 980.25
    }

}

Error de validación (400)

{
  "error": "Bad Request",
  "message": "Debe enviar ambos parámetros"
}

Error del servidor (500)

{
  "error": "Internal Server Error",
  "message": "Error en MySQL"
}
POST /api/v1/ventas

Body JSON

  • id_producto: requerido. Tipo: number.
  • id_cliente: requerido. Tipo: number.
  • cantidad: requerido. Tipo: number.
  • fecha_venta: requerido. Tipo: string en formato YYYY-MM-DD.
  • total: recomendado. Tipo: number. Se usa en el procedimiento almacenado asociado a la venta.

Códigos de respuesta

201 Created 400 Bad Request 500 Internal Server Error

Ejemplo de petición

{
  "id_producto": 10,
  "id_cliente": 5,
  "cantidad": 2,
  "fecha_venta": "2024-12-15",
  "total": 149.99
}

Respuesta exitosa (201)

{
  "status": "created",
  "message": "Venta registrada correctamente",
  "datos_registrados": {
    "id_producto": 10,
    "id_cliente": 5,
    "cantidad": 2,
    "fecha_venta": "2024-12-15",
    "total": 149.99
  }
}

Error de validación (400)

{
  "error": "Bad Request",
  "message": "todos los parámetros obligatorios"
}

Error del servidor (500)

{
  "error": "Internal Server Error",
  "message": "Error al Insertar"
}
